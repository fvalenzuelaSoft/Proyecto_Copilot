# Proyecto_Copilot
ABAP Copilot Assisted Development Project
Este repositorio contiene el desarrollo del proyecto final ABAP realizado con apoyo de GitHub Copilot, aplicando principios de arquitectura orientada a objetos, Clean ABAP y buenas prácticas en S/4HANA.

Objetivo

Diseñar e implementar una solución ABAP estructurada que incluya:

Arquitectura modular basada en principios SOLID

Separación clara de responsabilidades

Modelado de datos internos

Validaciones de negocio

Pruebas unitarias (ABAP Unit)

Documentación técnica mediante ABAPDoc

Alcance del proyecto

El proyecto incluye:

Diseño de arquitectura y flujo de componentes

Definición de clases e interfaces

Implementación de lógica de negocio

Validaciones específicas (NIT, DPI/CUI, email, teléfono, etc.)

Reporte estructurado bajo estándares FI

Documentación del proceso de prompting utilizado

Enfoque técnico

ABAP 7.4+

Programación Orientada a Objetos

Clean ABAP

ABAP Unit

Conversión de moneda y lógica financiera

Desarrollo asistido por IA (Copilot)

Estructura del repositorio

Documentos de análisis y diseño

Prompts utilizados por bloque de desarrollo

Evidencias de actividades asistidas

Archivos de arquitectura y flujo
